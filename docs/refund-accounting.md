# 退费账务规则

同意退费必须选择 settlement；驳回无需选择。

- reduce_fee：取消/减免与退款等额的费用，同时减少 payable 和 paid，累计增加 credited。原欠费差额保持不变；全额已缴费用取消后 payable=paid=0，状态为 paid（已结清）。
- return_payment：只退回款项，payable 不变，paid 减少，退款金额重新成为待缴费用。

例如已缴 300、应收 300，取消费用退款 300 后应收和已缴均为 0；仅退款 100 后应收 300、已缴 200、待缴 100。

原始 amount 和 discount 不覆盖；credited 单列累计退费减免。审批审计保留原账单与新余额、账务选择。迁移 sms:026-refund-accounting 只新增字段，不推断历史退款原因，不重新计算历史账单；旧审批 settlement=null，界面标识为历史处理。

退款审批在同一事务锁定申请、原收款和账单，复核累计已批准退款及账单余额；重复审批、退款超过原收款、退款超过账单已缴均拒绝。收款也锁定账单，避免余额互相覆盖。审批收件箱的批量操作为所有选中退款应用同一个明确选择；不同方式请分批处理。AI 工具同样需要 settlement，预览会说明账务后果。

本规则只登记线下账务，不代表真实银行退款；对账批次目前仍是收款流水统计，退款金额在财务报表中单列。
